## 这次补测的结论

- 换回双路 EPYC 7282 后，严格 NUMA 绑定的纯读取约为 57.33 / 57.83GB/s，双路 115.08GB/s；供电不齐时单路 7–8GB/s 的严重低带宽没有重现。
- 会话缓存在 128K 历史切换时把返回时间从约 54 秒降到 1.5–2.5 秒；代价是切换时约一到两秒的暂存/恢复，以及 6.32GiB 峰值内存。
- 12 道 Hermes 工程题在原始配置和缓存候选上都通过 12/12，净耗时差约 1.6%；单题因工具调用路径不同可摆动 18%–32%。
- 短输出微测不足以分辨 MTP 布局、prefill-pipe、spec-min-p 的小差异；这些参数已列入长输入/长输出、成对重复的追测清单。
- 250W 与 180W 对照中，180W 整请求慢约 8.25%，GPU 能量低约 13.1%；220W 作为折中档待测。
