# GPUServer-1 系统盘扩容完成

2026-10-15，用户明确授权从 500G 扩至 1T，完成后停止。本次采用 1 TiB = 1024 GiB。

## 操作与验收

- PVE：10.2.10.11，VM502，名称 GPUServer-1。
- 虚拟盘：virtio0，local-lvm:vm-502-disk-2，由 500 GiB 扩至 1024 GiB。
- 使用 `qm resize 502 virtio0 1024G` 完成在线磁盘扩容。Guest 立即识别 1,099,511,627,776 字节。
- 使用 parted 修复扩容后 GPT 备份表位置，扩展 vda3 至磁盘末端。vda1/vda2 与 vda3 起始扇区 2050048 均保持一致，vda3 分区 UUID 保持一致。
- 使用 pvresize 扩展 /dev/vda3；使用 lvextend 将 VG 空闲空间分配给 /dev/Debian-Template-vg/root；使用 resize2fs 完成 ext4 在线扩容。
- 最终 PV 约 1023.02 GiB，根 LV 约 1022.07 GiB，swap 保持约 976 MiB。
- `df -B1 /`：文件系统总可用容量口径 1,079,061,635,072 字节，已用 363,784,781,824 字节，可用 666,018,836,480 字节。`df -h /` 显示总量 1005G、可用 621G、使用率 36%。与虚拟磁盘容量的差额来自引导分区、swap、文件系统元数据和保留块。
- 根挂载保持 rw；Strata 容器 `strata-deploy-strata-1` 显示 Up 6 hours (healthy)，在线扩容未重启虚拟机或 Strata。
