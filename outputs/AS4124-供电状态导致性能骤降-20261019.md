# AS4124 供电状态导致性能骤降：定位记录

日期：2026-10-19。依据用户现场反复对照及六张附图；本记录未远程复测，也未更改服务或 BMC 设置。

## 已观察到的因果对照

1. 换上双路 EPYC 7452 后，原来的约 17 GB/s 内存读取仍存在。
2. 原先仅 JPW3、JPW4 对应两路电源上线；补齐 JPW1、JPW2 对应电源后，性能恢复。
3. 用户复测：四路缺任意一路均导致性能大幅下降；系统运行中补齐供电也能恢复。
4. 运行中移除电源后，AIDA64 曾出现 0 MB/s；相应截图 CPU Clock 显示 400 MHz。补齐电源后可恢复。

结论：供电可用状态是已复现的性能骤降触发条件。无需继续以 CPU/内存本体故障作为这个症状的首要解释。具体保护信号、BMC/CPLD/CPU 执行路径仍待日志或传感器确认。

## 官方资料与机制边界

- 用户提供的主板布局图标明 JPW1～JPW4 四个供电连接位置；本次未完成官方PDF正文的独立提取核验。
- Supermicro FAQ 15095：其他FatTwin平台中，已安装但未接交流电的电源可触发CPU降至最低频率，恢复供电可解除。
- Supermicro FAQ 41389、41893：其他平台存在电源故障/中断触发CPU节流的SMART Power机制。
- 这些资料支持“供电异常触发保护限速”这一解释，但不能直接确认AS4124使用同名开关或同一实现，也不据此建议关闭保护。

## 后续测试调整

1. 所有后续带宽和Strata测试固定四路电源正常上线。
2. 优先保存当前供电正常的PVE带宽、有效频率、BMC传感器及SEL基线，不必继续拔电源复现。
3. 重测Strata；历史低带宽环境下成绩保留为受供电状态限制的基线，不作为CPU架构/核心数对比依据。
4. 若需要评估7452升级收益，应与全供电状态下7282比较；旧7282尚未在此条件下复测，不能宣称已验证恢复后的性能。
5. PCIe AER是否同源尚无证据；另与2026-10-18保存的DapuStor链路日志比较。
6. 0 MB/s属于该次测试异常结果，不能理解为整机DRAM物理吞吐真正为零。

若进行供电连接维护，需要区分设计支持热插拔的PSU/交流输入，与主板JPW直流连接器；不将运行中供电恢复的现象当作主板直流连接器支持带电插拔的依据。
