## 方法及验证

- 与上次复用相同LIKWID、STREAM二进制，SHA-256一致。每项3次，总36个测试进程；18次STREAM数值校验全部通过。
- 按当前拓扑调整CPU编号：节点0物理核心0–31，节点1为32–63；排除SMT，校验LIKWID实际工作线程。
- LIKWID每路1536MB，16轮，本地并行first-touch。双路为独立本地工作组。
- STREAM单路membind，双路interleave(0,1)。其统计为逻辑读写字节，且双路页分布不同，不与LIKWID纯读取或AIDA64直接等同。
- 16线程对照分别取各插座前16个物理核心；与原7282的CCD分布、缓存容量并不完全一致，不能分离CPU更换与供电恢复的贡献。
- 测试完成状态：passed；虚拟机列表前后相同：True。
- MemAvailable前后：34.26/34.90 GiB。
- 系统vmstat前后：{'pswpin': 12729, 'pswpout': 96352, 'pgmajfault': 11607} / {'pswpin': 12920, 'pswpout': 100862, 'pgmajfault': 11776}。
- 子进程累计major faults：12；不将其直接解释为数组换页。
- SMBIOS仍报告条子Speed2933、Configured3200；仅作固件元数据，不单凭它确认实际时钟。
- 未停止虚拟机，未调整BIOS、电源保护、频率、resctrl或Strata配置。在线负载未隔离；本次是带宽复测，不是全容量稳定性测试。
