# PCIe 带宽与 Strata 性能关系（2026-10-19）

状态：completed。SC117 IQ3_S + Q8 PLE，Strata 0.1.45，双 RTX 2080 Ti layer split，32 vCPU、128 GiB、15 workers。两张推理卡均为 PCIe 3.0 x16；活动期间 `gpu_pcie_gen=3`、宽度 x16。

8 个请求覆盖 4K、32K、128K、240K 的简单与复杂任务，单并发、每项生成上限 512 tokens。`nvidia-smi dmon -s t` 每秒分别采集两张卡的 PCIe 收发速率，同时每 0.25 秒采集引擎状态、即时 tok/s、GPU 利用率和专家指标。以下 PCIe 数据来自逐卡采样，不使用 `pcie_share` 冒充带宽。

`p90` 是 90 百分位：把请求期间逐秒的双卡合计速率排序，取第 90% 位置的数，表示约 10% 的秒数高于它。它不是平均值。表中的双卡速率先按同一秒对齐再求和，没有把两张卡各自的 p90 直接相加。`RX` 是主机到 GPU；两张卡单向合计理论值约 31.5 GB/s。decode 的双向数值是两张卡 RX+TX 合计，对应的双向理论值约 63 GB/s。dmon 为 1 秒采样，表中 p90 与峰值描述突发，不是整段平均。

## 结论

decode 基本不受 PCIe 带宽限制。32K 以上简单任务解码中位 128.9 tok/s，而专家由 PCIe 提供的比例最高只有 0.10%，专家缓存命中率最低 98.8%。decode 的双向 PCIe p90 最高 8.4 GB/s，占两卡双向容量的 13.3%。长上下文的 decode 时间主要消耗在注意力、GPU 计算和 MTP 接受率上，而不是专家流式加载。

简单与复杂任务 prefill 都在约 2.2k tok/s 附近见顶，差别很小；两者 decode 差异却接近 2 倍。简单任务 MTP 接受率中位 97.0%，复杂任务只有 67.6%。这解释了为什么 PCIe 使用率相近时，两类请求的 decode 差距仍然很大。

prefill 同时接近 GPU 计算和 PCIe 突发限制。128K/240K 时 GPU 利用率中位已达到 99%–100%；两卡 RX p90 最高 23.0 GB/s，占单向理论容量 73.0%，双卡同时刻峰值最高 27.4 GB/s，达到单向容量的 87.1%。但整段平均双向流量最高约 10.4 GB/s，远低于链路持续上限，说明 PCIe 是阶段性突发与计算重叠，不是全程贯穿的单一瓶颈。继续增加 CPU 线程或改善 NUMA 都没有明显空间。

8 个请求的 `pcie_share` 都在 0.0%–0.1%，专家缓存命中率 98.8%–99.2%。在这个配置里，`pcie_share` 只能说明有极少数专家来自 PCIe，单独拿它判断链路瓶颈会产生误导。

限制：每项只运行一次，dmon 只有 1 秒分辨率；GPU 利用率与 PCIe 峰值同步出现，无法仅凭这些数据把 prefill 的 GPU 计算等待和 PCIe 等待精确拆开。要逐阶段归因，需要开启 `STRATA_DECODE_TIMING=1`、`STRATA_VERIFY_PROFILE=1` 或做 GPU trace。

逐项机器数据见 `measurements.csv`，完整逐秒样本见 `results.json`。
