# 后续验证与采购决策

## 用户约束

低带宽值得解决但不急，用户可接受暂不本地推理。熟悉服务器商家，可用现有内存作可退还抵押借16GB DDR4-2400 ECC RDIMM；也可搬AS4124去店里，但耗半天至一天。商家无方便借用的EPYC CPU。家中T630双E5-2697v4、无内存硬盘，可用作独立内存对照；搭建约2–3小时。暂不建议先搬GPU并重建推理环境。

用户报价（未独立核验成交行情，不作未来价格预测）：7302约300/颗，7443 1050/颗，7R13 1780/颗。一对分别600/2100/3560元。7V13和7763QS无明确当前报价或具体OPN/步进。

## 推荐验证顺序

1. 最少借4条匹配、已在商家平台验证的16GB DDR4-2400 ECC RDIMM；为减少二次往返，条件允许争取一次借8条，可先测4再测8。核对完整型号/料号。不是LRDIMM或ECC UDIMM。保留原条可退还所有权与现有编号，暂不永久置换。
2. AS4124双7282：每路A2+B2，共64GB；同PE、AIDA版本、默认参数，先核容量/2400MT/s/双通道，冷启动后两次读写复制延迟。比较已有四DB2与四CB2的约10/10.3/9.2GB/s记录。容量不同不用于完整Strata推理对照，仅作远超缓存的带宽测试。
3. 若明显改善，换回原4条相同槽位复测，再换借条确认（A/B/A，必要时B复验）；确定组相关再谈平换，而不是立刻宣布原条损坏。若依旧低，内存单独导致的解释弱化，但未排除两组共同平台训练/兼容问题。随后可借8条验证每路CDGH四通道完整配置，而非无条件一开始借16条。
4. T630作为第二阶段：USB PE即可测，不先装磁盘/迁GPU。原内存4条时每CPU A1/A2，8条时A1–A4、B1–B4；先核具体料号兼容及降频训练。已知正常借条作控制更有意义。原条在T630快只能证明能在该平台快，不能排除AS兼容；慢/不启动同样不能单独定条坏。
5. 内存对照未定位再考虑可退换的一对7302测试；需双路普通7302而非7302P，不能单颗与7282混搭。每路仍4条时不能期待官方八通道204.8GB/s。若换CPU改善，说明CPU型号/内存控制器/固件训练组合相关，不直接证明两颗7282损坏。无改善也不直接判主板损坏。
6. 7443若用户已愿长期升级，是优先保留的标准型号候选；否则不因排障购买整套。7R13/7V13/7763QS应在具体料号、支持、锁定状态、退换条件、额外用途及当前报价明确后比较。QS引入步进与固件支持变量，不优先用作健康基准。

## Strata后续对照规则

只在用户愿意投入时，固定引擎版本、精确模型文件/PLE、原始输入与实际输入长度、输出长度、并发、MTP/接受率、专家驻留/命中、缓存状态，分别记录prefill、TTFT、decode。现在GPUServer-1多了2070S且GPU0变为2070S；复现原双2080Ti基线时应按UUID明确选择原两张卡，不能直接沿用旧0/1编号而混入新卡。未经用户授权不执行新负载、重启服务或改CUDA配置。

## 用户补充时间成本后的优先级修订

用户明确：T630立即可用、无出行成本；借条要协调且通常需借还两次往返，未必借得到；搬AS4124去店可一次行程现场比较多组内存且便于置换，但需开车和连续半天。按真实约束，将首选改为T630测试原RDIMM，其次为有准备的AS4124到店现场验证；单独借还内存不再默认优先。此修订取代前面的推荐顺序，不重复停R730或迁GPU。

T630原8条RDIMM可每路A1–A4/B1–B4装四通道，PE USB启动，同软件测试，核频率/容量/时序。若恢复较高吞吐，削弱DIMM普遍性故障解释，重点转向AS4124的CPU/固件/兼容组合；仍不能仅凭跨平台测试排除AS专属兼容问题。慢则不能直接判坏，考虑借条或店内控制组。到店无备用EPYC时，可定内存组相关与否，不能保证一次分清CPU与主板。未确定原条损坏前不按坏条永久交易，先谈正常拆机回收和置换差价并保留原条到复验完。

AMD官方7002表：7282与7302均Rome/Zen2、16C32T、SP3双路、物理8通道、DDR4最高3200。7282基频2.8/最高boost3.2GHz、64MB L3、120W TDP、85.3GB/s并标注四通道2667优化；7302基频3.0/最高boost3.3GHz、128MB L3、155W TDP、八通道满配3200时204.8GB/s。主频提升基频7.14%、最高boost3.125%，不等于应用提升；缓存两倍。双路TDP标签合计增加70W，不等于实际墙上功耗恒增70W。

用户当前每路四条2933，不因换7302而自动变八通道：四通道裸接口约93.87GB/s/路；204.8是八通道3200的规格条件，不能用204.8/85.3预测当前配置倍数。若7302解决异常，收益包括原异常解除与正常型号差异，需分开表述。

7302按300/颗，一对600；可保留长期使用而非必然倒卖，待新CPU稳定、内存/PCIe/虚拟机验证后再卖7282。净成本600减两颗7282实际回收金额及加运费/手续费，未核验7282成交价不估净损失。必须普通7302而非7302P，确认正式料号、超微可用和退换。没有执行任何远程操作。
